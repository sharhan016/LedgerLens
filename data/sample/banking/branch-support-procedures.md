# Identity-safe support

Support agents verify the customer with approved factors before discussing account-specific
information. Agents must never request a full password, card PIN, or one-time password.
When verification is incomplete, the agent may provide only public product information and
the approved route for restoring access.

# Complaints

Every complaint receives a case identifier, category, summary, requested resolution, and
target date. Payment-service complaints are acknowledged within one working day; other
complaints are acknowledged within two. Escalation does not change the original received
date. The customer receives progress updates when the target date changes.

# Branch exceptions

Fee waivers, manual transaction releases, and identity exceptions require the authority
listed in the current delegation matrix. The employee records the approving person, reason,
duration, and supporting evidence. Verbal approval must be documented before branch close.
